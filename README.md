## 🔥 Why This Exists

GoCharting Terminal V2 launched on October 15, 2026, with upgraded Footprint (formerly Cluster), Market Profile, and Volume Profile tools. The platform is web-native — no Windows install, works in any browser. That's the appeal.

But orderflow configuration is personal and market-specific. A Footprint setup for BTC on a 5-second chart looks nothing like ES on a 1-minute chart. Traders rebuild these configurations every time they switch markets.

This manager stores them. Pre-tuned presets for major markets, one-click apply, version history, and export/import for sharing.

## 🧩 What It Does

### Footprint Presets
- Pre-tuned configurations for BTC, ETH, SOL, ES, NQ
- Candle type, column layout, color matrix
- Imbalance thresholds and ignore-zeroes settings
- Compatible with GoCharting's updated Footprint menu

### Profile Presets
- Market Profile (TPO) and Volume Profile configurations
- Session splits: Asia, London, New York
- Value area and extended level behavior
- Prior POC and Initial Balance settings

### Import/Export
- Save presets as JSON
- Share with your trading group
- Import presets from other traders

### Version History
- Keep the last 5 versions of each preset
- Roll back if a configuration doesn't work out
- Compare versions side by side

## ❓ FAQ

**Does this modify GoCharting?**
No — it stores configuration files and provides them for manual application. GoCharting is a web platform; you apply the preset settings in the terminal.

**Do I need a paid GoCharting plan?**
Footprint and advanced Profile tools require Premium. The free plan supports basic charts and limited Profile.

**Will I get banned?**
No — this is a configuration manager. It does not interact with GoCharting's servers, execute trades, or connect to any broker.

**Can I share presets with other traders?**
Yes — export as JSON and share the file.

**Does it work with GoCharting's mobile app?**
The presets target the web terminal. Mobile app configuration is separate.

**How do I uninstall?**
Delete the manager folder. No registry entries or system changes are made.
